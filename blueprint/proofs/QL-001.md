# QL-001: finite local-tail bound for Laplace remainders

## Status and scope

This is the fourth complete natural-language proof draft. It is not a frozen
theorem specification and authorizes no Lean implementation. Revision 4
corrects only the exact pinned Mathlib namespace ledger:
`integrableOn_exp_mul_Ioi` and `integral_exp_mul_Ioi` are root declarations.
The mathematical targets, proof, AE local premise, finite-dimensional source
adapter, and architecture are unchanged from revision 3, and new exact-commit
checks remain pending. Revision 3 kept the quantitative statements, constants,
real Gamma route, and common-baseline source semantics of revision 2, but gave
every conditional full-ray value an explicit witness in the revision-5
`IMP-001` relation. It uses the public Abel
composition theorem for the arbitrary-exception tail and the public absolute-
Bochner bridge for every model moment. Exact Lean signatures remain
intentionally absent until this complete proof and dependency architecture
receive fresh independent review. This correction makes no approval or
`lean_ready` claim.

The mathematical packet has two targets:

1. a generic local-plus-tail estimate for a remainder \(\phi\), expressed in
   terms of supplied constants \(k,K,X,L,\beta\);
2. a finite Watson decomposition which produces an explicit related value of
   the weighted amplitude after evaluating the finitely many model moments.

The packet does not derive numerical values of \(k,K,X,L\) for an arbitrary
amplitude. Concrete named-function applications must supply or bound them.

## Improper-integral and primitive convention required by this proof

For a finite set \(S\subset(k,\infty)\), ordinary improper convergence means
that the integral is split at the ordered points of \(S\), with separate
one-sided limits at every finite exceptional endpoint and a one-sided limit at
infinity. The Lean-facing relation uses Mathlib's Bochner `intervalIntegral`
on every compact truncated piece, with explicit `IntervalIntegrable` evidence;
only the endpoint passages are improper. This agrees with Olver's Riemann
meaning for the complex finite-dimensional source adapter while giving the generic Banach kernel
a native Mathlib interface. No cancellation across an exceptional point is
permitted. A Cauchy principal value is a different relation and is outside
this packet.

The reusable theorem does not assume that \(\phi\) is Bochner locally
integrable across \(S\). Instead it takes a normalized weighted primitive
certificate for the baseline \(X\):

1. \(F(k)=0\), and \(F\) is continuous on \([k,\infty)\);
2. on every compact interval \([a,b]\subset[k,\infty)\) avoiding \(S\), the
   baseline integrand is `IntervalIntegrable` and
   \[
     F(b)-F(a)=\int_a^b e^{-Xv}\,\phi(v)\,dv; \tag{QL.P}
   \]
3. \(\lVert F(t)\rVert\le L\) for every \(t\ge k\).

Continuity glues the regular-piece increments through the two independent
one-sided limits. This is strictly weaker than demanding absolute local
integrability at an exceptional point. Revision-6 `IMP-001` supplies both
interfaces used here: T06 constructs the conditional weighted tail from this
primitive, while T07 converts a separately proved `IntegrableOn` function into
the same relation at its exact Mathlib set-integral value. T07 is used only for
absolutely integrable model functions; it never identifies a conditional
relation with a totalized nonintegrable set integral. No second proper Riemann
integral implementation is planned.

On the local interval we additionally require
`AEStronglyMeasurable phi (volume.restrict (Set.Ioc 0 k))` as a direct premise.
The complex-valued, hence finite-dimensional, Olver source adapter obtains this
a.e. statement from proper Riemann integrability on a countable exhaustion by
compact subintervals away from zero. No implication from arbitrary Banach-
valued Riemann integrability is used. The adapter does not demand
pointwise `StronglyMeasurable` or Borel regularity: changing a proper-Riemann
representative on a null set can preserve its integral while destroying those
pointwise properties. Together with the local power majorant, the a.e.
premise supplies absolute integrability at zero. Choose \(k\) below every
positive exceptional point, so conditional convergence is needed only on the
certified tail.

## Exact preliminary identities

### QL-001-I01 - exponent normalization

For \(s,n\in\mathbb N\), set

\[
 \beta_s=\frac{s+\lambda}{\mu},
 \qquad
 \alpha_s=\frac{s+\lambda-\mu}{\mu}=\beta_s-1.
\]

Because \(\lambda,\mu>0\), every \(\beta_s>0\), hence
\(\alpha_s>-1\). In particular, the model powers are integrable at zero.

### QL-001-I02 - model moment

For \(x>0\),

\[
 \int_0^\infty e^{-xt}t^{\beta_s-1}\,dt
 =\Gamma(\beta_s)x^{-\beta_s}. \tag{QL.1}
\]

This is the pinned Mathlib theorem
`Real.integral_rpow_mul_exp_neg_mul_Ioi`. Its right-hand side is
\((1/x)^{\beta_s}\Gamma(\beta_s)\), equal to the displayed form for \(x>0\).

The equality theorem alone is not convergence evidence because Mathlib's set
integral is totalized. Before using a model as an ordinary-improper value,
apply the pinned root declaration
`integrableOn_rpow_mul_exp_neg_mul_rpow` from
`Mathlib.Analysis.SpecialFunctions.Gaussian.GaussianIntegral` with
\(p=1\), exponent \(\beta_s-1>-1\), and coefficient \(x>0\). It proves

\[
 t\longmapsto t^{\beta_s-1}e^{-xt}
 \quad\hbox{is `IntegrableOn` }(0,\infty).              \tag{QL.1a}
\]

Public IMP T07 then relates this model to the exact set-integral value QL.1.
Complex embedding and multiplication by \(a_s\) are continuous real-linear
maps, so generalized IMP T03 transports and combines the real model values
without introducing a second Gamma theorem.

### QL-001-I03 - finite decomposition

Define

\[
 p_n(t)=\sum_{s=0}^{n-1}a_st^{\beta_s-1},
 \qquad \phi_n(t)=q(t)-p_n(t).
\]

In relational form, finite linearity, the T07 witnesses from QL.1a, and QL.1
give

\[
 \int_0^\infty e^{-xt}q(t)\,dt
 -\sum_{s=0}^{n-1}a_s\Gamma(\beta_s)x^{-\beta_s}
 =\int_0^\infty e^{-xt}\phi_n(t)\,dt. \tag{QL.2}
\]

Here each displayed full-ray integral is shorthand for an explicitly related
value. Concretely, if \(R\) is related to the weighted remainder, generalized
IMP T03 constructs

\[
 Q=R+\sum_{s=0}^{n-1}a_s\Gamma(\beta_s)x^{-\beta_s}
\]

as a value related to the weighted amplitude. Thus QL.2 is an identity of
explicit values, not an equation between totalized conditional set integrals.
Public IMP T02 identifies any other value related to the same integrand,
start, and exceptional set. At \(n=0\), both sums are empty and \(\phi_0=q\).

## QL-001-T01 - generic local-tail estimate

### Hypotheses

Assume:

1. `AEStronglyMeasurable phi (volume.restrict (Set.Ioc 0 k))` directly; only
   the complex finite-dimensional Olver source adapter derives it from proper
   Riemann integrability on a countable exhaustion by
   \([\varepsilon,k]\), \(0<\varepsilon\le k\), without asserting pointwise
   Borel regularity or a general Banach-valued implication;
2. \(\beta>0\), \(k>0\), \(K\ge0\), and
   \[
     \lVert\phi(t)\rVert\le Kt^{\beta-1}
     \qquad(0<t\le k); \tag{QL.3}
   \]
3. \(S\) is a finite subset of \((k,\infty)\);
4. \(F\) is a normalized continuous baseline primitive satisfying QL.P on
   regular pieces;
5. \(\lVert F(t)\rVert\le L\) for all \(t\ge k\), with \(L\ge0\);
6. \(x>\max(X,0)\).

### Conclusion

There exists an explicit value \(I\in E\) such that

\[
 \operatorname{HasImp}
   (t\mapsto e^{-xt}\mathbin{\bullet}\phi(t),0,S,I)    \tag{QL.4a}
\]

and

\[
 \lVert I\rVert
 \le K\Gamma(\beta)x^{-\beta}
   +Le^{-(x-X)k}. \tag{QL.4}
\]

Here and below `HasImp` abbreviates public IMP T01. The theorem does not use a
Mathlib whole-set integral to denote the conditional value \(I\).

### Proof: local interval

By QL.3 and \(x>0\),

\[
 \lVert e^{-xt}\phi(t)\rVert
 \le K e^{-xt}t^{\beta-1}
 \qquad(0<t\le k).
\]

The scalar majorant is integrable on \((0,\infty)\) by the same pinned
integrability theorem used in QL.1a, specialized to exponent \(\beta-1\).
The a.e.-strong-measurability premise on \((0,k]\), multiplication by the
continuous scalar kernel, and `Integrable.mono'` therefore prove
`IntegrableOn` on \((0,k]\).
Using `intervalIntegrable_iff_integrableOn_Ioc_of_le` gives the honest
`IntervalIntegrable` witness for the local interval \([0,k]\), including when
\(\beta<1\) and the endpoint value at zero is arbitrary. Put

\[
 J=\int_0^k e^{-xt}\phi(t)\,dt.
\]

The norm-of-integral inequality and monotonicity then give

\[
 \left\lVert\int_0^k e^{-xt}\phi(t)\,dt\right\rVert
 \le K\int_0^k e^{-xt}t^{\beta-1}\,dt
 \le K\Gamma(\beta)x^{-\beta}. \tag{QL.5}
\]

The second inequality uses the already proved whole-ray scalar integrability
before applying set monotonicity, and only then rewrites the exact value by
QL.1. The totalized equality theorem is never used to infer integrability.

### Proof: public arbitrary-exception tail construction

Put \(h=x-X>0\) and \(g(t)=e^{-Xt}\phi(t)\). On a regular component
\([a,b]\), QL.P says

\[
 F(t)-F(a)=\int_a^t g(v)\,dv.
\]

Public IMP T05 is exactly the assertion that \(F\) has these increments,
continuity, and normalization. To invoke public IMP T06, it remains to prove
its two weighted-tail hypotheses. First, continuity of \(F\) on \([k,\infty)\)
makes \(t\mapsto e^{-ht}F(t)\) strongly measurable there, hence a.e. strongly
measurable for volume restricted to \((k,\infty)\), and

\[
 \lVert e^{-ht}F(t)\rVert\le Le^{-ht}\qquad(t>k).       \tag{QL.6a}
\]

Pinned `integrableOn_exp_mul_Ioi`, with coefficient \(-h<0\), and
`Integrable.mono'` prove

\[
 t\longmapsto e^{-ht}\mathbin{\bullet}F(t)
 \quad\hbox{is `IntegrableOn` }(k,\infty).              \tag{QL.6b}
\]

The same norm bound, `Real.tendsto_exp_neg_atTop_nhds_zero`, and \(L\ge0\)
give the second T06 premise

\[
 e^{-hR}\mathbin{\bullet}F(R)\longrightarrow0
 \qquad(R\to+\infty).                                  \tag{QL.6c}
\]

Public T06 now constructs, for the original arbitrary finite \(S\),

\[
 \operatorname{HasImp}
 \left(t\mapsto e^{-ht}\mathbin{\bullet}g(t),k,S,T\right),
 \qquad
 T=h\mathbin{\bullet}\int_{(k,\infty)}
       e^{-ht}\mathbin{\bullet}F(t)\,dt.               \tag{QL.6}
\]

The integrand is pointwise \(e^{-xt}\phi(t)\) by the real exponential law.
T06 proves this relation, without exposing any ordered-break representation to
QL, through its private finite-piece Abel/Fubini identity

\[
 \int_a^b e^{-ht}g(t)\,dt
 =e^{-hb}F(b)-e^{-ha}F(a)
   +h\int_a^b e^{-ht}F(t)\,dt. \tag{QL.Abel}
\]

It does not infer a pointwise derivative of \(F\). One proof substitutes the
increment formula into the last integral, uses Bochner Fubini on the finite
triangle \(a\le v\le t\le b\), evaluates
\(h\int_v^b e^{-ht}\,dt=e^{-hv}-e^{-hb}\), and rearranges. The needed Fubini
integrability follows from `IntervalIntegrable g` on the compact piece and the
bounded scalar kernel. No absolute integrability across a point of \(S\) is
used. The source route obtains T05 by
applying public IMP T08 to its baseline relation after removing the local
prefix; T08 returns a normalized continuous primitive tending to the baseline
value. Convergence plus continuity yields a global bound \(L\). Thus QL does
not duplicate IMP's finite-component construction.

### Proof: tail bound and local prepend

Because the set integral in T is honest by QL.6b,

\[
 \lVert T\rVert
 \le hL\int_{(k,\infty)}e^{-ht}\,dt
 =Le^{-hk}. \tag{QL.7}
\]

The equality uses pinned `integral_exp_mul_Ioi` with \(-h<0\); positivity
of \(h\) justifies the cancellation and no totalized division is used.

Finally apply public IMP T04 with \(a=0\), the honest local
`IntervalIntegrable` witness, and tail value \(T\). It prepends \([0,k]\) and
constructs QL.4a at the explicit value \(I=J+T\). The triangle inequality,
QL.5, and QL.7 prove QL.4. This is the only local-to-tail join.

### Why the hypotheses do not contain the conclusion

The primitive bound is imposed at one baseline weight \(X\), not at the target
weight \(x\), and contains no requested Laplace integral or target error. It is
strictly reusable: conditional convergence at \(X\) implies existence of some
finite \(L\), while concrete applications may provide a computable bound on
\(L\).

## QL-001-T02 - finite Watson remainder bound

Fix \(n,\lambda,\mu,a,q\) and set \(\beta_s, p_n,\phi_n\) as above. Assume the
T01 hypotheses for \(\phi_n\) with
\(\beta=\beta_n=(n+\lambda)/\mu\). The target conclusion is a single
existential conjunction: there is a \(Q\) for which both QL.9a and QL.9 hold.
Its relational conjunct is

\[
 \exists Q\in\mathbb C,\quad
 \operatorname{HasImp}
   (t\mapsto e^{-xt}q(t),0,S,Q),                       \tag{QL.9a}
\]

and that same existential witness satisfies

\[
 \left\lVert
 Q
 -\sum_{s=0}^{n-1}
   a_s\Gamma(\beta_s)x^{-\beta_s}
 \right\rVert
 \le K\Gamma(\beta_n)x^{-\beta_n}
   +Le^{-(x-X)k}. \tag{QL.9}
\]

Apply T01 to obtain a value \(R\) related to the weighted remainder and
satisfying QL.4. For every \(s<n\), QL.1a proves absolute integrability of the
real model. Public IMP T07 relates it to its exact QL.1 set-integral value.
Apply generalized IMP T03 first through the real-to-complex continuous linear
map and fixed multiplication by \(a_s\), and then to the finite family
consisting of the remainder relation on \(S\) and the model relations on the
empty set. The literal finite union is \(S\), and T03 constructs QL.9a with

\[
 Q=R+\sum_{s=0}^{n-1}a_s\Gamma(\beta_s)x^{-\beta_s}.   \tag{QL.9b}
\]

Subtracting the finite model from QL.9b leaves \(R\), so QL.4 proves QL.9
without any further analytic estimate. If a caller already supplies another
explicit value \(Q'\) with the same T01 relation, public IMP T02 gives
\(Q'=Q\), and QL.9 therefore applies to every explicit related value.

This is the reusable finite theorem needed by OLV-001. At \(n=0\), no model
integrability witness, coefficient, or Gamma value is used: the T03 family
reduces to the T01 remainder witness for \(q\), and the approximant is empty.

## Nonemptiness and regressions

### Exact model

Take \(q(t)=a_0t^{\beta_0-1}\), \(n=1\), and \(\phi_1=0\), where
\(\beta_0=\lambda/\mu\). Choose any \(k>0\), \(K=L=0\), and \(X=0\).
QL.9 becomes the exact Gamma moment.

### Order zero

At \(n=0\), QL.9 bounds the whole integral of \(q\). No access to \(a_0\) is
required by the finite sum, although a source-derived local bound may naturally
use the next coefficient.

### Negative majorants

Neither \(K<0\) nor \(L<0\) is accepted. Their nonnegativity is required before
monotonicity and norm bounds.

### Missing tail control

Fix any local model on \((0,k]\). Add to \(q\) an arbitrarily large
nonnegative bump supported in \([k+1,k+2]\). The local expansion is unchanged,
but the Laplace integral at a fixed \(x\) changes arbitrarily. Thus local data
alone cannot imply QL.9.

### Eventual convergence is not a uniform numeric bound

For a family indexed by \(A>0\), add \(A\) times the same remote bump. Every
member has an eventually convergent Laplace integral, but no common numeric
\(L\) follows. Uniform bounds require an explicit family hypothesis.

### Conditional interior singularity

Let \(c>k\), and multiply

\[
  t\longmapsto \frac{\sin(1/(t-c))}{t-c}
\]

by a smooth cutoff supported in a small neighborhood of \(c\). The separate
one-sided improper integrals at \(c\) converge by the Dirichlet test after the
substitution \(u=1/(t-c)\), but the norm is not locally integrable there. Its
weighted accumulated primitive nevertheless extends continuously across
\(c\). The finite-exceptional theorem must accept this example with
\(S=\{c\}\); the local-Bochner adapter must not claim to accept it. A symmetric
principal-value cutoff is not used.

### Boundary \(x=X\)

At \(x=X\), \(h=0\) and the bounded-primitive argument no longer supplies
decay. Strict \(x>X\) is essential.

### End-to-end public-API consumer regression

A disposable consumer imports only the public IMP Basic, Bochner, and Abel
modules plus QL's pinned Mathlib dependencies. For arbitrary finite
\(S\subset(k,\infty)\), it must perform all of the following without unfolding
T01, naming ordered breaks, or copying finite-component recursion:

1. begin with a baseline-\(X\) relation for the weighted source amplitude and
   the raw finite model functions, not with a T05 primitive already assumed;
2. prove baseline absolute integrability of every model, apply T07 and
   generalized T03 to subtract the finite model, and obtain the baseline
   remainder relation;
3. derive the local `IntervalIntegrable` witness at zero from the restricted
   a.e.-strong-measurability premise, \(\beta>0\), and QL.3;
4. use T04 to move the baseline remainder relation from zero to \(k\), apply
   T08 in the forward direction to obtain a normalized continuous primitive
   tending to its tail value, and derive a finite global bound \(L\) from that
   convergence plus continuity;
5. at the target \(x\), derive QL.6b and QL.6c from T05, \(h>0\), and the flat
   bound on \(F\);
6. call public T06 to obtain the exact tail relation, then T04 to prepend the
   local interval and obtain T01's value \(R\);
7. for every \(s<n\), separately prove QL.1a at the target \(x\), call T07,
   and only then rewrite
   the model value by the Gamma equality;
8. use generalized T03 to transport real model values to \(\mathbb C\), apply
   coefficients, combine them with \(R\), and produce QL.9a--QL.9b on the
   literal union \(S\);
9. use T02 to identify any independently supplied value for the same weighted
   amplitude.

The regression fails if the Gamma equality is used as integrability evidence,
if a conditional full-ray value is represented by Mathlib's totalized set
integral, or if it begins by assuming the primitive or model relations already
exist. For \(n=0\), the model steps are empty and require no coefficient
access; T08 is applied directly to the baseline relation for \(q\).
