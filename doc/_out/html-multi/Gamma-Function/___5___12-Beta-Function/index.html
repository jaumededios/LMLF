5.12. §5.12 Beta Function🔗

Fractional powers have principal values unless a contour record explicitly carries continuous logarithm lifts. Complex.betaIntegral denotes the convergent Euler integral; the meromorphic continuation is represented by meromorphicBeta, with meromorphicBetaDefined excluding its Gamma poles. The integral records state their convergence conditions explicitly.

Lean vocabulary · meromorphic beta continuation
noncomputable def meromorphicBeta (a b : ℂ) : ℂ := Complex.Gamma a * Complex.Gamma b / Complex.Gamma (a + b)
Lean vocabulary · finite meromorphic-beta locus
def meromorphicBetaDefined (a b : ℂ) : Prop := Complex.Gamma a ≠ 0 ∧ Complex.Gamma b ≠ 0 ∧ Complex.Gamma (a + b) ≠ 0
