§5.11(i) Poincaré-Type Expansions🔗

The coefficient streams below are canonical maps. A finite-state computation isolates each new coefficient in the DLMF convolution, and the scaled-Gamma coefficients are reconstructed from that stream. The recurrence and initial value are exposed as semantic laws, rather than hiding the data behind a selected existence witness.

The finite products used by the coefficient formulas are introduced once in this shared vocabulary block before any numbered formula uses them.

§5.11(ii) Error Bounds and Exponential Improvement🔗

The paragraph immediately before E10 gives two further, genuinely distinct complex remainder estimates. To make the first omitted source index explicit, the following definitions use one-based n and truncate through n - 1.

noncomputable def complexStirlingTerm (k : ℕ) (z : ℂ) : ℂ := (bernoulli (2 * k) : ℂ) / ((2 * k : ℕ) * (2 * k - 1 : ℕ) * z ^ (2 * k - 1))noncomputable def complexDigammaTerm (k : ℕ) (z : ℂ) : ℂ := -(bernoulli (2 * k) : ℂ) / ((2 * k : ℕ) * z ^ (2 * k))

§5.11(iii) Ratios🔗
